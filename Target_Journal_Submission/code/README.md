# Group-conformal prediction intervals for NIR calibration under deployment shift

Code, configuration and result files for the manuscript *“Group-conformal calibration of near-infrared prediction intervals for new
seasons, instruments and regions using PLS diagnostics”* (submitted to *Talanta*).

Everything reported in the paper – every number, table and figure – is regenerated by one command from public
data. Nothing is typed by hand into tables: `experiments/aggregate*.py` write the result files, and
`experiments/make_tables.py`, `experiments/make_figures.py` and `../manuscript/build_manuscript.py` read them.

## 1. Installation

Python 3.11, CPU only (≈ 4 cores, 8 GB RAM is enough). GPU is not needed; the optional 1D-CNN uses CUDA or
Apple-MPS automatically if present (`src/utils.py::device`).

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt          # or: conda env create -f environment.yml
python -m pytest -q tests                # 8 unit tests (PLS vs scikit-learn, jackknife+ solver vs brute force,
                                         # unit-disjoint folds, hierarchical coverage on synthetic data)
```

The manuscript DOCX is rendered with Node.js (`npm install docx`) and LibreOffice (`soffice`, Writer) for PDF.

## 2. Data

`python scripts/download_data.py` downloads ≈ 470 MB into `data/raw/` and checks SHA-256 checksums:

| Data set | Source | Licence | Used for |
|---|---|---|---|
| Mango DMC and NIR spectra v5 (file `MangoDMC_NIR_Data_v4.csv`) | Mendeley Data, doi:10.17632/46htwnp833.5 | CC BY 4.0 | season, instrument, population shift |
| Open Soil Spectral Library v1.2 (vis-NIR, soil lab, site tables) | soilspectroscopy.org public bucket | CC BY (KSSL), JRC licence (LUCAS) | region, campaign, library shift |
| Corn (80 samples × 3 NIR instruments) | Eigenvector Research data-set page | public | instrument shift |
| IDRC 2002 tablet shoot-out | Eigenvector Research data-set page | public | exchangeable control / instrument shift |

Raw data are **not** redistributed in this repository (LUCAS licence; size). Parsed arrays are cached in
`data/processed/` on first use.

## 3. Reproducing the study

```bash
python run_all.py --mode quick    # ~15 min: 2 folds/task, seed 0 → results_quick/, figures_quick/, tables_quick/
python run_all.py --mode full     # complete study (≈ 42 core-hours, about half a day on 4 cores; resumable)
cd ../manuscript && python build_manuscript.py Final_Manuscript.docx text_results   # main text (DOCX)
python audit_manuscript.py                       # 33 consistency checks of text vs data/results
python build_supplementary.py                    # ../supplementary/Supplementary_Material.docx
python build_letters.py                          # cover_letter.docx, highlights.docx
soffice --headless --convert-to pdf Final_Manuscript.docx
```

`run_all.py` executes, in order: data download → unit tests → main experiments (E1–E3, E5; 12 tasks × 5 seeds)
→ post-hoc iteration (GC-D2, GC-CQR) → robustness and sensitivity (E4, E7) → 1D-CNN check → clipped WCP and
leave-one-cultivar-out → isolated timing (E6) → aggregation and statistics → error and decision analysis (E8, E9)
→ figures → tables → graphical abstract.

Measured cost of the reported run (from the time stamps in `results/experiment_logs/`): main experiments 16.7
core-hours, post-hoc iteration 8.7, robustness/sensitivity 6.9, 1D-CNN 9.3 (CPU), clipped WCP and cultivar
test 0.6 — about 42 core-hours in total.

Per-spectrum predictions are written as Parquet files (≈ 1 GB) that are **not** committed (`.gitignore`); every
reported number is computed from the committed per-group CSV files, except the cluster bootstrap and error
analysis (`analysis_points.py`), which re-read the Parquet files regenerated by `run_all.py`. Experiments run in parallel worker
processes (`--workers`); completed folds are cached in `results/main/partial/` so an interrupted run resumes.

## 6. Leakage control

Every outer and inner split is *unit-disjoint*: a fruit, soil sample, corn sample or tablet never contributes to
the training set of a model that predicts any of its spectra (`engine.py` asserts this for every outer fold;
`crossfit.make_folds` enforces it for inner folds; `tests/test_core.py::test_folds_are_unit_disjoint`). This is
essential because 7,100 mango fruit were scanned on several instruments and the corn/tablet samples were measured
on every instrument.

## 7. Seeds and determinism

Seeds 0–4 are fixed in advance (`config/experiment_config.json`) and control random unit splits, bootstrap
resamples, GPR subsets, LightGBM and CNN initialisation. Leave-one-group-out components are deterministic.
Results are reported as means over seeds; no seed was selected after viewing results.
